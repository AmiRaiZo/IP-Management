Public domain and port

Apply changes to the live server configuration.

Enter only the hostname, without https:// or a path.

Saving updates Nginx, the SSL certificate, the Gunicorn listener and HTTP-to-HTTPS redirect. The new domain must resolve to this server or a correctly configured proxy. If UFW is active, the new TCP port is opened automatically; your VPS provider firewall may also need a rule. The old site's Nginx configuration and certificate are removed after the new HTTPS endpoint passes its health check. A failed change triggers rollback.

Trusted update source

For safety, updates are pinned to the trusted repository configured by the server installer. This prevents a compromised account from redirecting the root updater to arbitrary code.

To switch to a different trusted repository, change GITHUB_REPO in the server environment and redeploy the app. This page cannot change the trusted source.

Telegram security notifications and bot

Login alerts plus interactive IP add/search commands.

Login alerts include username, source IP, Jalali time, hostname, failure reason and a keyed password fingerprint. For safety, the raw attempted password and 2FA code are never stored or sent. Send ربات to your bot to open the inline menu with اد آیپی and سرچ. Search results never include saved connection passwords. Bot Token and Chat ID are encrypted at rest; the webhook is protected by a secret token. HTTPS and a publicly reachable APP_PUBLIC_URL are required for Telegram menu callbacks.

Readable TXT backup / export

Download application records in a structured UTF-8 text file.

The export includes users and roles, groups, IP records and saved connection passwords, access rules, application settings, audit history, recent security events, and selected readable text source files. Account password hashes, authenticator seeds, and Telegram credentials are excluded. This is not a complete, restorable backup: environment secrets, the SQLite database file, binary uploads, and the operating system are not included. Keep the downloaded file encrypted and private.
